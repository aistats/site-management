## Summary

Replace the 2020-era AISTATS conference stub with a template that matches how `aistats2023`–`aistats2025` (and the early `aistats2026` site) actually run: remote theme `aistats/jekyll-theme`, markdown content pages, config-driven chairs and deadlines, and the shared `_includes` / `_doc` layout. The stub should seed a new yearly repo with empty placeholders and clear comments, not leftover venue copy from a prior conference.

## Motivation

The stub last changed on 2020-08-05. Since then every live conference site moved to `aistats/jekyll-theme`, dropped most of the stub's HTML pages, and converged on a markdown page set. New organisers who "Create from Template" still get:

- Theme `lawrennd/proceedings` (wrong; README still points there too)
- `index.html` with `layout: home` instead of `index.md` with `layout: default`
- Venue-oriented HTML (`accommodation`, `local`, `registration`, `submission`, `submit`) that recent years underscore or delete
- No CFP, CoC, dates, FAQs, camera-ready, poster, awards, invited, schedule, or `other.md`
- No local `_includes` for banner and key dates
- Organiser docs under `doc/` instead of `_doc/`
- Chair roles and deadline schema that omit General Chairs, Journal-to-Conference, and richer deadline fields (`important`, `enddate`)

`aistats2026` already shows the cost: it started from the stub, patched theme and committee by hand, kept the wrong README lineage, and still lacks the standard content pages. Refreshing the stub once is cheaper than teaching each year's chairs to reconstruct the 2025 shape.

## Detailed Description

### Reference shape

Treat **aistats2025** as the primary reference (complete modern site). Use **aistats2024** as a secondary check for naming and includes. Use **aistats2026** only for early-year minimalism (what must exist on day one) and for chair-role names that have already evolved (e.g. Inclusivity, Workshop, Journal-to-Conference). Ignore 2020–2021 HTML layouts and 2022 transitional filenames (`cfp.md`, `code-conduct.md`) as targets.

### Target stub contents

**Keep / update**

| Path | Change |
|------|--------|
| `Gemfile` | Keep current github-pages / remote-theme gems; optionally note `webrick` for local serve |
| `_config.yml` | Point `remote_theme` at `aistats/jekyll-theme`; add `banner_title`, `repository: aistats/aistats20XX`; placeholder venue/year/instance; modern chair role stubs; richer deadline examples with comments |
| `committee.html` | Match 2025/2026: `layout: default`, render `site.conference.chairs` via theme includes |
| `README.md` | Describe this repo as the **conference template**, theme `aistats/jekyll-theme`, and point to `_doc/` for organiser workflow |
| `assets/images/` | Keep a placeholder banner slot; document required logo/banner filenames |

**Add (markdown stubs with front matter + short TODO body)**

- `index.md` (`layout: default`, `weight: 1`) — short home blurb using `site.conference.*`
- `call-for-papers.md` (`weight: 2`)
- `code-of-conduct.md` (`weight: 2`)
- `dates.md` (`weight: 1`) — `{% include listdates.html %}`
- `faqs.md` (`weight: 5`)
- `reviewer_guidelines.md` (`weight: 6`)
- `ac_guidelines.md` (`weight: 6`) — optional early, present in 2024–2025
- `invited.md` (`weight: 5`)
- `schedule.md` (`weight: 2`)
- `awards.md` (`weight: 8`)
- `camera.md` (`weight: 7`)
- `poster.md` (`weight: 4`)
- `registration.md` (`weight: 3`)
- `other.md` (`layout: other`, `hide: true`)

**Add (shared fragments and docs)**

- `_includes/banner.html`, `_includes/listdates.html`, `_includes/tabledates.html` — copy from 2025, keep generic
- `_doc/` — move and refresh current `doc/` organiser guides; do not publish as site pages

**Remove or stop shipping as live pages**

- `index.html`, `accommodation.html`, `local.html`, `registration.html`, `submission.html`, `submit.html`
- If venue pages are still useful as starting points, keep them underscored (`_accommodation.html`, `_local.html`) like 2023–2024, not in the nav

### Config contract

The stub `_config.yml` should document (via comments) the fields recent sites rely on:

- Site: `baseurl: "/aistats20XX/"`, `repository`, `github_username`, `author.email`, `banner`, `banner_title`, `remote_theme: aistats/jekyll-theme`, `style: aistats`, `ghub.repository`
- Conference: `year`, `instance`, `location`, `venue`, `dates`, `submission.{show,url,name}`, `proceedings`, `draft`, `hide_tentative`
- Deadlines: `name`, `type`, `date`, optional `time` / `enddate` / `important`
- Chairs: at least General, Program, Workflow, Local, Publication, Sponsorship, D&I/Inclusivity, Journal-to-Conference; leave people blocks empty with comments

Placeholders must use `20XX` (or clear `TBA`) so a new year never ships last year's Thailand/Morocco copy by accident.

### Out of scope for this CIP

- Rewriting `aistats/jekyll-theme` itself
- Back-porting the new stub into already-running yearly repos (optional follow-up)
- Content for a specific conference year (CFP text, real dates, real chairs)
- Deciding whether society-site admin steps stay only on `aistats.github.io` (already clarified there)

### Alternatives considered

1. **Leave stub; document divergence in README only** — cheap, but every new year re-learns the gap (already visible in 2026).
2. **Make `aistats2025` the GitHub template repo** — preserves a full year of real content that organisers must scrub; worse than a cleaned stub.
3. **New empty repo beside stub** — splits "official template" identity; prefer updating `stub` in place so existing "Create from Template" links keep working.

## Implementation Plan

1. **Branch and baseline**
   - Create branch `cip0001-refresh-stub`
   - Snapshot current stub file list in this CIP's implementation notes if needed

2. **Config and theme**
   - Rewrite `_config.yml` to the modern contract with `20XX` placeholders
   - Update `README.md` for template role and correct theme URL

3. **Page set**
   - Add markdown stubs listed above
   - Replace `committee.html` with the 2025/2026 pattern
   - Remove obsolete live HTML pages (or underscore venue helpers)

4. **Includes and docs**
   - Add `_includes` from 2025 (sanitised)
   - Move `doc/` → `_doc/` and fix internal links / checklist for the new page names

5. **Smoke check**
   - Diff stub tree against 2025 page/include presence matrix
   - Optionally build locally with a throwaway `baseurl` to confirm Jekyll loads

6. **Handoff**
   - Update society-site README if template instructions need `_doc` or new first steps
   - Mark CIP Implemented / Closed after review

## Backward Compatibility

Existing yearly repos are unchanged. New repos created from the template after merge get the new layout. Anyone following old stub docs that mention `doc/`, `submission.html`, or `lawrennd/proceedings` will need the updated README/`_doc`. GitHub "Create from Template" continues to use this same repository name.

## Testing Strategy

- File-presence checklist vs 2023–2025 common pages
- Grep stub for forbidden leftovers: `lawrennd/proceedings`, real city names, real years other than `20XX`
- Local `bundle exec jekyll build` if environment allows
- Manual review that nav weights and `hide` flags match the intended early-conference surface
