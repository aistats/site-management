# Task: Manifest schema and 2026 sync inventory

## Description

Define the YAML manifest format for `sync-virtual` (what must be synced) and encode the first concrete 2026 inventory from the stub page set and `aistats2026` `sync-from-virtual` mapping. Document extract strategy names and optional per-page policy fields (`required`, preferred drift handling).

## Acceptance Criteria

- [ ] Manifest schema documented in CIP-0004 or adjacent `scripts/sync_virtual/README` (fields: `year`, `virtual_base`, `target_repo`, `pages[]` with at least `id`, `url`, `out`, `extract`)
- [ ] Optional per-page policy fields sketched (`required`, `on_drift`, or equivalent)
- [ ] Default 2026 manifest lists the main-site inventory pages from CIP-0004
- [ ] Extract strategies named (`main_after_nav`, `event_bios`, `dates_tables`, …) with one-line intent each
- [ ] Year-repo override path noted (`virtual-sync.yml`)

## Implementation Notes

Start under `site-management/scripts/sync_virtual/`. Do not implement fetch yet—schema and YAML only.
