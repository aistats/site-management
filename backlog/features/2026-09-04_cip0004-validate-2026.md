# Task: Validate sync against AISTATS 2026

## Description

Run `sync-virtual` against live or fixture 2026 virtual URLs on a clone of `aistats2026`. Review the report; selectively `--fill-missing` and/or apply pages; use the virtual update request where year-site (or intended primary) text should win. Open a PR from faithful generated content—not the paraphrased `sync-from-virtual` branch as gold prose.

## Acceptance Criteria

- [ ] Sync report produced for 2026 manifest against current `aistats2026` tree
- [ ] Spot-check: applied pages match virtual wording (not paraphrased backfill)
- [ ] Missing primary pages filled only via explicit flags where agreed
- [ ] Drift handled via apply **or** virtual update request (documented in PR/report)
- [ ] PR opened (or ready) against `aistats2026` without force-pushing unreviewed bulk overwrite to `gh-pages`

## Implementation Notes

Prefer a new branch from current `gh-pages`. Treat `sync-from-virtual` as inventory only.
